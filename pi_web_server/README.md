# 树莓派 3B+ 智能嵌入式控制台 & 自带独立热点服务

本工程是为**电子科技大学·智能嵌入式系统课程设计**量身定制的完整软硬件落地套件。  
它将树莓派 3B+ 的板载 Wi-Fi 芯片配置为**独立 AP 热点（无须连接路由器或校园网）**，并部署了一套基于 **Python Flask** 的现代化响应式物联网控制台。

---

## 🎯 对应课程设计考核指标

1. **基础套 B - 3. 系统应用类型**：
   - **题目 1 (防火墙/路由/热点)**：树莓派自带独立 WiFi 热点，支持客户端通过 WiFi 接入并分配独立 IP 子网；
   - **题目 2 (Web 服务器)**：轻量级 Flask Web 容器，精美响应式 UI 适配手机与电脑，实时监控 SoC 核心温度、4核 CPU 负荷、1GB 内存及 TF 卡存储占用；
2. **基础套 B - 4. 软件开发类型**：
   - **题目 1 (无间道发报机)**：内置完整的摩斯电码解密终端与信号输入接口，支持物理电键/软件按键敲击，实时解密并在上位机/手机端翻译显示；
3. **高阶/接口扩展预留**：
   - 内置 **USB / CSI 摄像头 MJPEG 实时推流管道**，未插摄像头时自动输出仿真测试雷达帧，插上摄像头即刻转为真实视频监控，便于无缝衔接高阶姿态识别与视觉 AI 算法。

## 🍓 第二步：将代码部署至树莓派 3B+

### 1. 拷贝工程到树莓派
你有两种极其简单的方式将文件拷入树莓派：
* **方式 A（网线/同一WiFi通过 SCP 传输）**：
  在电脑终端执行：
  ```bash
  scp -r d:/Codex/智嵌/pi_web_server pi@raspberrypi.local:/home/pi/
  ```
* **方式 B（用普通 U 盘拷贝）**：
  把 `pi_web_server` 文件夹复制到 U 盘，插到树莓派上拷贝至 `/home/pi/` 目录。

---

### 2. 树莓派一键开启独立 AP 热点
在树莓派终端中执行：

```bash
cd /home/pi/pi_web_server
sudo bash scripts/setup_hotspot.sh
```

脚本会自动检测系统网络服务（支持 NetworkManager `nmcli` 与经典 `hostapd+dnsmasq`），并自动创建：
* **Wi-Fi 热点名 (SSID)**：`Pi-SmartLab`
* **默认密码**：`raspberry123`
* **树莓派网关 IP**：`192.168.4.1`

---

### 3. 一键安装开机自启动服务（脱机免屏幕运行）
在树莓派终端中执行：

```bash
sudo bash scripts/install_service.sh
```

此命令会将控制台服务注册为 Linux 系统底层的 `systemd` 守护服务（`pi-web.service`）。  
**从此树莓派拔掉显示器和键盘，只要通电开机，就会自动发射热点、自动在后台启动 Web 服务！**

## 📱 第三步：手机 / 电脑连接热点与演示操作

1. **手机搜索 Wi-Fi**：
   * 打开手机无线局域网搜索，找到 `Pi-SmartLab`；
   * 输入密码：`raspberry123`，点击连接；
2. **浏览器直接访问**：
   * 打开手机上的 Safari 或 Chrome 浏览器；
   * 在地址栏输入：
     ```text
     http://192.168.4.1:5000
     ```
     或者（苹果设备/支持 mDNS 的设备）：
     ```text
     http://pi.local:5000
     ```
3. **现场演示与答辩要点**：
   * **展示 1 (系统监控)**：给老师展示 CPU 负荷率与 SoC 芯片核心温度的实时毫秒级更新，证明真实读取了 Linux 底层 `/sys/class/thermal/thermal_zone0/temp` 硬件传感器；
   * **展示 2 (无间道发报机)**：手机端点击短按 `.` 与长按 `-`，或点击快捷按键 `[SOS]`，展示手机端到树莓派后端的毫秒级翻译与蜂鸣声音效；
   * **展示 3 (外设视觉)**：插上 USB 摄像头后，控制台视频窗自动播放真实画面，说明软硬件链路完全打通。

## 🛠️ 常用运维命令

* **查看 Web 服务运行日志**：
  ```bash
  sudo journalctl -u pi-web.service -f
  ```
* **手动重启 Web 服务**：
  ```bash
  sudo systemctl restart pi-web.service
  ```
* **手动恢复连接寝室/家庭 WiFi（关闭热点）**：
  ```bash
  sudo nmcli con down "Pi-Hotspot"
  sudo nmcli con up "你原来的WiFi名字"
  ```
