方向一：树莓派智能嵌入式课设细化要求（高阶 + 基础套A/B）

模块分类 子方向 / 题目 具体任务内容 关键考核指标与硬性限制
高阶（必做） 算法板端移植
(任选 1 项)		 • 机器学习 / 姿态识别 / 人工智能目标检测
• WiFi 非合作式运动检测 / 其他自拟前沿算法
• 要求：将算法或其核心计算模块部署在板端运行，建议结合外设形成完整作品 		• 难点考察：ARM Linux 环境配置（OpenCV / Python / OpenVINO / TFLite）
• 工具链选择：自举开发 vs 交叉编译
• 算力划分：板端驱动与推理 vs 上位机协同
基础：套 A
(底层与驱动
两项均必做)		 1. 系统安装
(必做)		 • 树莓派上安装 Win10 (ARM) / OpenWRT / openEuler (配置 OpenCV 或 TensorFlow) / Matlab 等不同系统 • 硬性指标：必须安装过不少于 2 种不同版本的系统
• 限制：同一系列（如 Ubuntu 不同版本）仅算 1 种
2. 接口应用
(必做)		 • 利用 USB 口、UART 串口、WiFi 或蓝牙接口连接摄像头、传感器等外设，将数据通过网络传送到 PC 机显示 • 有效性判定：需证明数据真实通信并可视化
• 无效操作：单纯读写 U 盘不算，单纯在 /dev 看到设备名不算
基础：套 B
(网络与应用
各选 1 项)		 1. 系统应用
(3 选 1)		 ① 防火墙与路由：Pi 设为防火墙+路由(+热点)+NAT，手机连WiFi，Pi网线连校园网并过滤访问；
② Web 服务器：搭建 Web 服务并设计美观网页，展示个人大作业或课设报告；
③ FTP 服务器：配置 FTP 服务作为移动文件存储站。 		• 强调网络服务链路畅通性与内网穿透/访问能力；
• Web 服务要求前端界面排版美观大方。
2. 软件开发
(3 选 1)		 ① 无间道发报机：利用 GPIO 开关/短接发报，板端识别后通过网络发到 PC/手机翻译成文字；
② 魔幻键盘：Pi 外接键盘，网络连接 PC，重映射键位实现趣味交互效果；
③ 官方自拟：参考 www.raspberrypi.org 自拟软硬件交互应用。 		• 突出软硬件联动与网络通信闭环；
• 鼓励打造趣味性高、交互直观的交互原型。
组织与评分要点：2~3 人一组，华为 Atlas200 可不做。不要求最终 100% 完美成功，但必须有足够的工作量；若遇到难以逾越的技术障碍，需在报告中详细阐明失败机理、排查定位过程与尝试过的解决思路。

方向二：《机器学习初步与实践》课设规范 (CV / ML)

课题选项 核心设计任务与指标 算法模型推荐与实现路径
题目 1：字母与数字识别
经典视觉		 • 手写样本：在纸上手写 0~9 数字与 26 个英文字母（不区分大小写），拍摄制作成样本图片；
• 输入输出：输入计算机，程序能够自动多分类识别并输出正确字符；
• 规格要求：图片需归一化为固定分辨率（如 50×50 或 32×32）。 		• 逻辑回归多分类（Softmax）
• 多层感知机（MLP）/ 经典 LeNet-5 CNN
• SVM 搭配 HOG 特征提取
题目 2：文本情感识别
NLP 文本分类		 • 输入数据：输入一段中文文字；
• 判别目标：自动分析并判别情感倾向，类别固定为 3 类：积极、消极、中性。 		• TF-IDF / 词袋模型 + 朴素贝叶斯 / SVM
• Word2Vec / FastText + LSTM / BiLSTM
• 轻量级中文预训练模型（如 RoBERTa-Tiny）
题目 3：其他自选题目
灵活扩展		 • 可选方向：歌曲音乐风格分类、人脸表情识别、字符验证码识别、股票走势预测、环境温度时序预测等。 • 需自行构建规范的训练集、验证集与测试集，给出完整的 Confusion Matrix 与准确率/F1 指标。
提交与答辩规范： 截止日期：2026 年 10 月 17 日前上传成电慕课。压缩包命名必须为 2026Fall-ML-组序号-选题名称.zip，内含：①课程设计报告(*.doc)、②汇报PPT(*.PPT)、③课程设计检查指标(*.xlsx)、④程序工程源码。答辩每组汇报 5 分钟 + 问答 3 分钟，组长介绍分工，现场必须进行运行演示（Live Demo）或播放录制视频。

方向三：《智能控制》课设要求（信通院·杨鍊老师）

课题方向 系统核心功能指标 关键技术与硬件配套
应用一：智能健康管理系统
健康感知与控制		 (1) 运动姿态识别与纠错：基于嵌入式平台连接传感器（摄像头或毫米波雷达），实时识别运动姿态，记录健身动作次数，并实现动作错误纠正提醒；
(2) 饮食热量监控与闭环推荐：监管每日摄入食物种类及分量，分析摄入 vs 消耗能量平衡，智能生成饮食与运动定制推荐方案。 		• 嵌入式主控 + USB/CSI 相机 / 毫米波雷达
• 骨骼关键点检测（MediaPipe Pose / 轻量 YOLO-Pose）
• 动作夹角几何判别算法 + 热量数据库匹配
应用二：大模型批判式思维机器人
具身智能教育		 (1) 语音自然对话：嵌入式端实现语音采集与识别（ASR），完成自然口语问答交互；
(2) 启发式思维训练：利用大语言模型（LLM）对用户语音进行智能解析，培养批判性思维，后台构建训练画像；
(3) 表情专注度感知：实时分析人脸表情与专注度状态，统计数据同步推送至家长手机端。 		• 麦克风阵列 + 扬声器 + 显示屏 + 摄像头
• 嵌入式端 VAD 语音断句 + ASR + TTS
• 大模型 API 结构化 Prompt 调优 + 面部表情识别
选项三：自拟智能控制项目
完整工程创新		 • 自主设计一个与智能控制有关的完整工程项目；
• 明确拟解决的核心问题、系统工作闭环与控制指标。 		• 输出完整的硬件架构拓扑、控制软件流程图与核心控制/感知算法方案。
交付与答辩要素：须提交完整项目技术方案书（包含整体系统框架、硬件原理与选型、软件流程图、核心算法介绍）并准备 PPT 现场答辩。

💡 跨课设高效复用策略与树莓派 3B+ (1GB RAM) 适配建议

“一石三鸟”多课设高效联动方案：
  • 姿态/视觉动作识别主线：以“人体姿态检测与动作规范性分析”为核心技术内核——在【树莓派课设】中作为高阶必做任务（轻量 MediaPipe Pose 或 TFLite 跑在 3B+ 上，USB 相机抓流）；在【智能控制课设】中自然扩展为“智能健康管理系统”的动作识别与纠正功能；在【机器学习课设】中则可对应“手部手势识别”或“面部表情识别”子模块，极大减少多门课的重复开发成本！
  • 树莓派 3B+ 资源约束避坑指南：3B+ 仅有 1GB 内存，千万避免在板上编译大型深度学习框架或跑原生 YOLOv8；推荐采用 TFLite / ONNX Runtime 配合量化模型（INT8），或采用“树莓派采集数据推流 + PC/服务器轻量推理 + 树莓派受控执行”的分布式边缘计算架构；基础系统建议选用官方 64-bit Lite 系统或 openEuler Embedded。
  • 里程碑时间线推进策略： 第 1 阶段（本周内）：报送树莓派课设选题组合（如：高阶姿态识别 + 基础套A底层系统）；
    第 2 阶段（10月17日前）：率先冲刺《机器学习初步与实践》慕课提交与答辩；
    第 3 阶段（10月下旬~18周）：将核心算法迁移部署至树莓派 3B+ 硬件，完成软硬件联调与展示答辩。
